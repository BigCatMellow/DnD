# Project scope — Wurdren's Road
MAPS_Lean [Project Bootstrap](https://github.com/BigCatMellow/MAPS_Lean/blob/main/playbook/PROJECT_BOOTSTRAP.md) guides this bounded game content work. The 10Kings wiki remains world authority and is not modified.

**Observable DONE for first playable release:** choose Wurdren, have a complete canonical reference route, resolve an opening physical problem using transparent d20 rules, talk to independent NPCs with distinct incentives, reach a social/physical outcome with at least two viable paths, preserve resources/decisions in a GitHub save, and resume later without making novel canon claims.

**First session status:** Wurdren selected, first decision pending. Four areas of risk: dangerous scene timing, tone collapse into RPG exposition, invented biography, confusing gameplay outcomes with Two Sons canon.

**Exclusions:** no 10Kings main edit, no Wurdren birth or family lore, no mages or supernatural creatures, no spell conversion, no merge to main without review, no automatic campaign action on player's behalf.

**Verification:** validate JSON schema and connected scene references, inspect canonical pointers, manual action/no-action/bargain/retreat paths, inspect save at first actual action, get independent review when available. This is a provisional gameplay prototype, not the approved Sunday novel.
