# The Ashen Road — chat-playable fantasy campaign

An original, solo-friendly tabletop adventure run **in a chat**, backed by a compact GitHub source of truth.

**Quick start:** read [PLAYER START](adventures/01-vanishing-mile/PLAYER_START.md), select a character from [pregens](pregens/INDEX.md), then tell the game master which character you chose. The GM runs scenes, dice, enemies, NPCs, and consequences. Your actions are not restricted to listed options.

The repo is a **game reference and save ledger**, not a chatbot or autonomous runner. Chat is the play surface. The GM reads the smallest relevant files, resolves outcomes openly, and updates the save after agreed checkpoints. Do not present GM spoilers to the player.

## Project
- [Project brief](docs/PROJECT.md) · [Roadmap](docs/ROADMAP.md) · [Sources and licensing](docs/SOURCES.md)
- Rules identity: **D&D-style d20 core and action economy**, Pathfinder-inspired exploration and consequence design, plus explicit solo-mode adaptations. This is a house game, not official D&D or Pathfinder.
- First campaign: **The Ashen Road**; adventure 01: **The Vanishing Mile** (level 2).
- Content is authored for this campaign; see [SOURCES](docs/SOURCES.md) for rule provenance and licensing.

**Status:** v0.1 playable starter kit. Not an encyclopedia or a complete conversion of either game system. Review any changes to its rules before using them in an ongoing save.
