# Rules router — House Rules v0.1

The **single mechanics authority** is this directory. Start with only the relevant owner:

| Question | Read |
| --- | --- |
| Dice, tests, ability scores, graduated success | [CORE](CORE.md) |
| Initiative, action economy, damage, death, conditions | [COMBAT](COMBAT.md) |
| Investigation, travel, tracking, faction pressure | [EXPLORATION](EXPLORATION.md) |
| Character creation, levels, rests | [CHARACTERS](CHARACTERS.md) |
| Starter spells, equipment, consumables | [SPELLS_GEAR](SPELLS_GEAR.md) |
| GM pacing, consent, difficulty, solo encounters | [GM](GM.md) |

No combination of D&D's and Pathfinder's competing attack/defense/action rules is permitted. v0.1 is a consistent **house system**. When a rule is absent, make a minimal ruling, label it provisional and capture it in the journal rather than silently treating a book not in this repo as authoritative.
