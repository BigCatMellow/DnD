# Roadmap / release boundaries

## v0.1 — First playable session (this PR)
- [x] Project and rules decision, reference routing, original campaign premise.
- [x] Core adjudication and solo-mode rulebook.
- [x] Starter bestiary, characters, location/NPC/faction indices.
- [x] Branching first adventure and structured initial save.
- [x] Validation script for schemas, references and scene connectivity.
- [ ] Outside review on PR and correction of review findings.
- [ ] Player chooses hero; first real player action and saved checkpoint (requires actual play).

## v0.2 — Verified sessions 1–3
**Trigger:** actual feedback from first session. Add levels 3–4, more spells/gear, 1–2 follow-on adventures, downtime and settlement consequences. Validate after actual use, not through speculative content volume.

## v0.3 — Longer campaign
Add the Salt Road / Crown of Rain arcs, travel tables, regional encounter roster, progression and faction clocks. Separate player-facing discoveries from unrevealed GM plans.

## Later only if needed
Tool-assisted state updates and battle map support; searchable generated indexes; automated roll log. Do not create a backend, web UI, agent orchestration or a whole-book transcription without a clear need.
